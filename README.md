# Multi Task
扩展`01_libos`，在其之上添加类似现代操作系统的分时多任务功能，允许os可以加载多个任务到内存中，并给予它们时间片运行。

主要改造：
- `user`：添加构建脚本，自动生成`linker.ld`，编译用户程序时使用特定的`BASE_ADDRESS`
- `os/loader`：用户程序加载，将它们一次性加载到os内存的指定位置
- `os/TaskManager`：任务管理器，提供多任务的TCB管理、任务切换等功能
- `os/yield`：提供任务主动让步
- `os/timer_interrpt`：基于时钟中断完成多任务切换

核心：
- 每一个任务都有一个内核栈和用户栈
- `yield`、时钟中断后，进入内核栈，通过`__switch`切换到其它task的控制流
- 对应内核栈通过`__restore`恢复到用户程序
