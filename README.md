# libos

构建一个简易的批处理操作系统，我们将若干个用户程序和系统打包在一个二进制文件中，然后逐个执行用户程序。

- 用户程序运行在u-mode
- 用户程序崩溃不影响os，os会开始运行下一个程序
- 用户程序通过系统调用向控制台输出文字，以及结束自身
- 提供`write`、`exit`系统调用
- 不提供内存方面的屏蔽


# Q&A
## 如何将用户程序和os打包到一个文件中

可以使用链接文件将用户程序打包到数据段中，os在执行程序时，为其准备栈，并从数据段加载它们到指定位置，而后转换成正确的特权级，跳转到用户程序第一行代码。

## 如何实现系统调用
1. 操作系统设置stvec，提供traphandler
2. 用户程序调用ecall，并使用x10, x11, x12, x17等寄存器保存系统调用参数，返回值，系统调用id
3. 操作系统traphandler接收到trap，识别出是来自ecall的系统调用，并调用对应功能
4. 返回用户程序

细节：
1. traphandler首先需要保存用户程序现场
2. traphandler退出时、或os将执行权交给用户程序时，恢复用户程序现场
3. 系统调用通过一个id、两个参数、一个返回值地址描述？

## OS启动流程
- RustSBI加载0x80200000，OS第一行代码被放置到此处
- OS设置trap handler
- OS进入调度循环
- 加载程序
