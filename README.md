# Multi Task
1. [✅] 解决用户程序编译问题：编写脚本，生成不同的linker.ld，指定不同的base address
2. [✅] os模块新增loader，启动时将程序加载到正确的执行位置
3. [✅] os模块修改用户栈、内核栈，每一个程序一份
4. [_] os模块新增scheduler，用于选择一个程序执行调度
    - 内核最初运行在自己的栈
    - sched时，需将内核的运行状态压在内核栈上，跳入用户栈，恢复TCB中的上下文，开始运行用户代码
5. [_] os模块接收时钟中断，用于跳出当前程序并执行调度
6. [_] os模块提供yield系统调用，用于当前程序自行放弃执行
